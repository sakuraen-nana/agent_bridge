## 1. 局域网发现

- [ ] 1.1 `discovery.rs`：信标编解码（协议版本/uuid/短名/主机名/端口）、3 秒广播循环（全局广播 + 按接口 prefix 定向广播）、监听与自过滤、30 秒过期的最近活跃表；验证：单测——信标序列化往返、非 JSON/异协议包丢弃、本机 uuid 忽略、过期移除（时间注入）
- [ ] 1.2 接入服务端生命周期（随 runtime 启停）；UDP 绑定失败 → 状态标记不阻断；`AppSnapshot.discovery`（可用性）；验证：单测（先占 UDP 端口再起服务端 → 主服务照常、状态为不可用）；`discovered_devices()` 桥接查询

## 2. 配对服务端

- [ ] 2.1 `pairing.rs`：待决表（单条）、决定通道、长轮询（120 秒）、忙响应（429）；`POST /pair/request` 端点（免 token）与留痕（token 状态标「免认证端点」）；验证：单测/集成——入表与决定流转、忙拒绝、超时（缩短注入）、决定前响应不含任何配置信息
- [ ] 2.2 桥接面：`pairing_pending()` / `respond_pairing(approve)`；验证：集成——无待决时 respond 报错；同意路径返回长期 token 配置

## 3. 出站配对与配置写入

- [ ] 3.1 `config::add_peer`：不存在追加、同 uuid 幂等覆盖、注释与未知键保留；验证：单测（两情形 + 文件往返）
- [ ] 3.2 `request_pairing(uuid)`：从发现表取来源 IP → 调对端 `/pair/request`（总超时 125 秒）→ 同意即 `add_peer`；被拒/超时/忙/未发现 分别回执；验证：集成（进程内双服务端互配：同意后本端出现 [[peer]] 且 CLI 连通；拒绝不落盘）
