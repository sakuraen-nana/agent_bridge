- [x] 1.2 接入服务端生命周期（随 runtime 启停）；UDP 绑定失败 → 状态标记不阻断；`AppSnapshot.discovery`（可用性）；验证：单测（先占 UDP 端口再起服务端 → 主服务照常、状态为不可用）；`discovered_devices()` 桥接查询 —— 证据：`bind_fails_when_port_held_without_reuse` 单测 + 真机 §8.6（占用 37778 起实例：主服务「运行中（端口 39505）」照常、面板「发现：UDP 端口 37778 绑定失败（发现功能不可用）」（截图）；防火墙行随之只列 TCP）；`discovered_devices()` 实装并被 GUI/集成测试使用

## 2. 配对服务端

- [x] 2.1 `pairing.rs`：待决表（单条）、决定通道、长轮询（120 秒）、忙响应（429）；`POST /pair/request` 端点（免 token）与留痕（token 状态标「免认证端点」）；验证：单测/集成——入表与决定流转、忙拒绝、超时（缩短注入）、决定前响应不含任何配置信息 —— 证据：`server_test.rs` 新增 3 项（同意返回含长期 token 的配置且 uuid/来源校验、拒绝+忙 429+非法 uuid 400、超时（`pair_timeout_secs=1` 注入）回执并清表）；留痕实测「token=免认证端点（配对请求）」；真机：忙 429、真机 120 秒超时（§8.3）
- [x] 2.2 桥接面：`pairing_pending()` / `respond_pairing(approve)`；验证：集成——无待决时 respond 报错；同意路径返回长期 token 配置 —— 证据：`pairing_pending` 被 GUI 轮询使用（widget 测试覆盖弹窗同意）；`respond_pairing` 决定路径在真机配对全环中执行（§8.2）；无待决报错为 `pairing::decide` 的显式分支（单测语境经 server_test 决定/清表覆盖）

## 3. 出站配对与配置写入

## 8. Linux 双实例实跑（本机）

- [x] 8.1 发现：两实例（不同 XDG/端口）互见（≤3 秒级）且信标无凭据（抓包或日志核对）；停播 30 秒后过期移除；留证 —— 证据：抓包样本 `{"proto":"agent-bridge/1","uuid":"78a2eb83-…","short_name":null,"hostname":"<被控机主机名>","port":39502}`（`含 token 字段: False`）；互见见 §8.2 截图（A 的发现列表含 B）；过期移除由单测覆盖（真机未再等 30 秒）
- [x] 8.2 配对全链路：GUI 发起配对 → 对端弹窗 → 同意 → 发起方配置自动出现 [[peer]] → CLI 以该设备连通 hello（long-term token）；留证 —— 证据（编排实跑）：A=集成测试实例（真实点击「发起配对」）、B=独立 GUI 进程；B 日志 `#1 已同意 · 已返回本机配置（含长期 token，值不落日志）` + 随后两条 `POST /hello · token=有效（长期）`；A 测试断言：发现互见 → 按钮点击 → `已配对：` 结果 → 配置含 B 的 uuid → **CLI hello 退出码 0** → All tests passed；对端对话框截图（含请求方 UUID/来源 IP）
- [x] 8.3 拒绝与超时：拒绝 → 无写入、明确回执；超时（120 秒）→ 回执；留证（超时可缩短注入验证 + 真机等待一次）—— 证据：拒绝（`pairing_loop_test`：rejected 且 peers 为空）；超时双证：注入 1 秒（Rust 级，回执+清表+不写入）与**真机 120 秒**（`curl` 实测 `{"approved":false,"reason":"超时（无人决定）"}`、耗时 2m0.007s；B 日志 `#16 超时（无人决定）`）
- [x] 8.4 忙：对端已有待决时第二请求 → 忙拒绝；留证 —— 证据：真机 `curl` 第二请求 `{"error":"已有待处理的配对请求"}` + B 日志 `#5 已拒绝 · 429 · 已有待处理的配对请求`；单测同断言（server_test 429）
- [x] 8.5 在线三态：对端正常/停服/重置 token 三种情形下列表状态与文案（截图）；留证 —— 证据：三张截图（s10-status-online/offline/unauth）：绿「在线」/ 灰「离线（连接失败：…脱敏…）」/ 橙「在线但凭据失效（token 被重置或轮换），请重新配对」
