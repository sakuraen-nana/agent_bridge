# agent-bridge

局域网远程执行桥：在被控机上启动一个受 token 保护的小型 HTTP 服务，agent（AI Agent，
通常运行在另一台机器上）通过它远程执行命令与取回文件，实现"无需人工介入的远程操作闭环"
（拉仓库、触发构建与测试、推送提交、取回产物）。

工具**独立、自包含、零第三方依赖**：只要求目标机有任意可用的 Python 3（≥3.7）。
它与任何被控项目无耦合，因此**推荐部署在被控项目目录之外**——被控项目怎么切分支、切提交
都不影响通道可用性，工具文件也不会出现在被控项目的工作树里形成干扰。

- **`run.py`**（统一入口，位于工具根目录）：跨平台单一入口，不保留 `.sh` / `.bat` 薄封装。
  入口自定位，可在任意工作目录下调用；完成解释器/依赖环境检测与 OS 识别后启动程序主体
  （缺省或 `server` → 被控端；`scan` / `hello` / `exec` / `download` → 客户端）
- **`src/agent_bridge/server.py`**（被控端）：仅 Python 标准库，Linux / Windows 通用
- **`src/agent_bridge/client.py`**（agent 侧）：仅 Python 标准库，四个子命令

## 一、启动服务器（在被控机上）

```bash
python3 run.py      # Linux（在工具根目录下执行；也可用绝对路径从任意目录调用）
python run.py       # Windows（或 py -3 run.py）

# 指定默认工作目录（推荐：无需先 cd 到目标目录）
python3 run.py server --workdir /path/to/project     # Linux
python run.py server --workdir D:\project            # Windows
```

启动后控制台会醒目输出本次随机 **token**、端口（固定 37777）、运行用户、工作目录、
局域网 IP 列表与调用示例。**每次重启 token 都会轮换**，旧 token 立即失效。

**默认工作目录**（`--workdir`）是 exec 缺省与相对 `cwd`、download 相对路径、hello 的
`cwd` 字段共同的基准；横幅会在该行标注它的来源（来自 `--workdir` 或取启动时目录）。
不传该参数时取服务器进程启动时所在的目录，行为与旧版一致。目录无效——不存在、不是
目录、存在但不可访问——时**拒绝启动**：输出指明原因的错误并以退出码 2 退出，不会
退回默认目录。

> `--workdir` 必须写在 `server` 之后（`python run.py server --workdir …`）。
> 入口以第一个位置参数决定分发目标，`python run.py --workdir …` 会被判为未知子命令。

### Windows 防火墙首次授权

第一次启动时 Windows 会弹出防火墙授权框（对 `python.exe` 开放 37777 端口），
请选择 **"允许"（专用/私有网络）**。若错过了弹窗，可到
"控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙" 手工勾选 python 的
**专用网络** 权限，或临时关闭防火墙后再试。

> exec 的相对路径与 download 均以**默认工作目录**为基准——推荐用 `--workdir` 显式指定，
> 而不是依赖"先 cd 过去再启动"。

## 二、填写 token 文档（在被控机 or agent 侧机器）

1. 复制工具根目录下的 `bridge.local.md.example` 为同目录的 `bridge.local.md`；
2. **直接把被控机控制台输出的启动横幅整段粘贴进去**即可——横幅的 `Token` 行与
   「局域网 IP」行会被自动识别为 token 与 host，无需手工改写。也可以照模板手工填
   `token:` / `host:` 字段，两种写法可混用；
3. `bridge.local.md` 已被 .gitignore 排除，**不得加入任何同步渠道**（详见模板内警示）。

解析规则：按行序**后者覆盖前者**，所以粘贴横幅后在文件末尾另写一行 `host:` 即可改指
其他机器；**值为空的行不覆盖已有取值**，因此模板里留空的字段不会清掉粘贴进来的内容。
横幅的 IP 行列出多个地址时（多网卡、含 VPN），优先取其中的私网地址
（`10.` / `172.16-31.` / `192.168.`），无则取第一个。

token 失效（服务器重启过）时，client 会输出标准处置提示：到被控机控制台抄录最新
token 更新文档即可。文档可含多组 `token` / `host` 字段（例如同时记录多台被控机）；
调用时也可用 `--host` / `--token` 临时覆盖文档取值。

## 三、agent 使用流程（在 agent 侧机器上）

```bash
cd <工具根目录>      # 入口自定位，也可在任意目录下用绝对路径调用

# 1) 扫描局域网，定位并确认 bridge 服务器（缺省扫运行 client 的那台机器的主网段 /24，秒级完成）
python3 run.py scan

# 2) 校验服务器，打印基本信息（主机名 / 用户 / 工作目录 / 启动时刻）
python3 run.py hello

# 3) 远程执行命令（流式输出；远端命令的退出码即本命令的退出码）
python3 run.py exec "git -C <仓库目录> pull"
python3 run.py exec "git -C <仓库目录> push" --timeout 120

# 4) 取回远程文件（缺省保存为当前目录同名文件；--out 可指定）
python3 run.py download <远程文件路径>

# token / host 均可用参数临时覆盖（如换机、token 刚轮换未及更新文档）
python3 run.py hello --host 192.168.1.10 --token <新token>
```

scan 结果分两组输出："已确认的 bridge 服务器"（token 验证通过）与
"未知服务"（端口开放但 token 不匹配）。扫描网段可用 `--cidr 192.168.1.0/24` 覆盖。

### client 退出码

| 码 | 含义 |
| --- | --- |
| 0 | 成功（exec 时 = 远端命令退出码；scan 时 = 至少发现一台已确认服务器） |
| 1 | 业务失败（远端路径不存在、下载不完整、scan 无结果等） |
| 2 | 本地配置/用法错误（token 文档缺失、token 未填等） |
| 3 | 网络连接失败或流式响应中断 |
| 4 | token 被拒（404）——按提示更新 token 文档后重试 |

### 注意事项

- **并发**：服务器不强制命令间互斥，多个 exec 可同时进行；调用方应自行串行化
  （同一仓库上的操作并行会互相干扰）。
- **超时**：远端命令缺省 1800 秒超时，超时进程树会被终止并以 `timed_out:true` 收尾；
  长构建/长测试请用 `--timeout` 给足余量。
- **Windows cmd 转义**：复杂引号嵌套的命令建议改经 exec 执行单行
  `python -c "…"` 或先落一个脚本文件再执行，规避 cmd.exe 转义差异。

## 四、安全声明（务必知悉）

- **持 token 即完全控制被控机**：exec 以服务器运行用户执行任意命令，等价于把 SSH
  凭据交给了持有者。
- **明文 HTTP**：token 以查询参数明文传输，无加密无审计——仅限可信局域网使用。
- **不用即关**：服务器进程常驻即通道常开；用完请关闭（Ctrl+C / 关闭窗口），token 随进程消失。
- **泄露即失守**：token 仅存服务器进程内存、每次启动轮换；`bridge.local.md` 含当前有效
  token，严禁入库、严禁进入任何同步渠道；怀疑泄露时重启服务器即可使旧 token 全部作废。

## 五、服务器控制台输出说明

被控端控制台会**实时留痕所有请求（含被拒）**，采用分节排版：请求行（编号 / 时间 /
来源 / 路径）→ `▸` 起首的小节（空行分隔、字段对齐）→ `└` 收尾行。

| 请求类型 | 控制台显示内容 |
| --- | --- |
| 被拒（token 无效/缺失） | 时间、来源 IP:端口、路径、token 状态（脱敏）、请求体限量预览（不解析不执行）；对请求方仍返回统一 404 |
| hello | 请求行 + 响应逐字段完整显示（版本 / 主机名 / 用户 / 系统 / 工作目录 / IP / 启动时刻） |
| exec | 全部参数（command / cwd / timeout_seconds，含缺省标注）→ 实时输出（与客户端收到的内容逐字同步，不加前缀）→ 结束行（退出码 / 耗时 / 是否超时 / 客户端断开） |
| download | 调用方传入的原始 `path` + 解析后的完整绝对路径 + 发送结果（不显示文件内容） |
| 认证通过但被拒（400 / 404） | 请求参数完整显示 + 拒绝原因（与成功请求同等，不再用截断预览） |

> **完整性口径**：通过 token 认证的请求，参数与响应一律完整显示；仅当一段整块文本
> （如请求体、响应）超过 64KB 时才截断，并在原处标注「已省略 N 字节」。exec 的实时
> 输出流不受该上限限制。
>
> 多条命令并发执行时控制台输出会交错；调用方应串行化调用。

## 六、网络环境

工具全程只在局域网内通信，且仅用 Python 标准库——**不依赖外网、代理或任何包管理器**；
被控机只需任意可用的 Python 3.7+。若某台机器访问本仓库的通道不通，可由使用方经离线
或局域网传递一份目录，行为不变。
